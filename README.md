# 影癫插件 for Symedia

面向 Symedia / Emby / 115 的影癫（MADREEL）自动化工具，提供签到、搜索、订阅补集、解锁和 115 直连转存。

> 当前版本：**v0.8.1**

## 主要功能

- **搜索并转存**：按 TMDB ID 或片名查询影癫资源，支持电影、剧集和指定季
- **完整资源信息**：画质、片源、HDR、音轨、字幕、大小、积分、115 / ED2K / 磁力类型和集数
- **Emby 入库检测**：显示是否入库、已入库哪些集、当前缺哪些集
- **订阅补集**：优先选择能补齐最多缺失集数的资源，再比较完整度和画质
- **防重复解锁**：已入库集数自动跳过；刚转存但 Emby 尚未刷新的集数会在设定时间内继续跳过
- **定时签到**：随机时间窗口自动签到
- **115 直连转存**：解锁后直接调用 115 接口转存到指定目录，不依赖 Telegram 机器人消息
- **榜单**：TMDB 热门 / 高分榜、豆瓣高分 / 热门电影 / 热门剧集
- **发现筛选**：TMDB / 豆瓣 / 豆瓣榜单 / 豆瓣片单，支持类型、排序、年代、地区、风格和入库状态筛选
- **订阅中心**：电影订阅、电视剧订阅、订阅日历、匹配规则和运行配置
- **添加订阅弹窗**：片名搜索 TMDB、自动读取总集数、选择网盘类型
- **移动端 / PWA**：支持 iPhone 灵动岛安全区，可添加到主屏幕

## 部署

项目目录示例：

```bash
/vol1/1000/tools/yingdian-plugin
```

启动或重建：

```bash
cd /vol1/1000/tools/yingdian-plugin
docker compose up -d --build
```

访问：

```text
http://NAS-IP:8909
```

浏览器登录页：

```text
http://NAS-IP:6080/vnc.html
```

登录影癫后，登录状态保存在 `browser-profile`，正常情况下重启容器不需要重新登录。

## 首次配置

打开插件「设置」页面，依次配置：

1. **Emby 入库检测**
   - Emby 地址，例如 `http://192.168.1.6:8096`
   - Emby API Key
   - 启用入库检测
   - 自动跳过已入库和正在转存的集数
2. **115 直连转存**
   - 115 Cookie
   - 目标目录 CID，例如 `/影视整理/bot转存` 对应的 CID
3. **TMDB**
   - TMDB API Key，用于片名搜索、剧集总集数和榜单
4. **签到与订阅**
   - 签到开关、积分上限、过滤词

密钥类字段留空保存时保持原值，不会清空。

## 订阅规则

剧集订阅会先读取 Emby 当前已入库集数，然后按以下顺序选择资源：

1. 能补齐的新集数最多
2. 资源本身包含的集数更多
3. 画质、片源、HDR、音轨和字幕更好
4. 积分更低

例如 Emby 已有第 `1、2、5` 集，影癫同时存在 `1-2`、`5`、`1-9`：

- `1-2` 和 `5` 会被判定为无需重复转存
- `1-9` 会标注可补 `3-4,6-9`
- 自动订阅会优先选择完整度更高的 `1-9`

## 115 转存说明

115 分享链接会直接转存到设置中的目标目录。ED2K 和磁力链接只展示，不会自动提交 115 离线任务。

## 项目结构

```text
app/
├─ main.py          Web 页面与 API
├─ config.py        配置读写
├─ store.py         SQLite 签到、订阅、解锁和防重复记录
├─ library.py       Emby 入库 / 集数检测
├─ scoring.py       资源评分和缺集覆盖判断
├─ tmdb.py          TMDB 搜索、季集信息和榜单
├─ browser_client.py 影癫浏览器自动化
├─ transfer115.py   115 直连转存
├─ service.py       搜索、订阅、解锁业务逻辑
├─ scheduler.py     定时任务
└─ templates/       页面模板
browser/             noVNC + Chromium 容器
```

## 注意

- 影癫登录失效时，需要在 noVNC 页面重新登录一次
- 115 Cookie 失效后，转存会失败，需要在设置中更新 Cookie
- Emby 未配置时，搜索和转存仍可使用，但不会显示入库状态，也无法自动跳过已入库集数
- 仅供个人媒体自动化使用，请遵守站点规则和当地法律法规
